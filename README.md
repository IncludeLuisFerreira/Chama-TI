# ChamaTI-Trabalho prático de programação de dispositivos móveis
![Static Badge](https://img.shields.io/badge/Status%3A-Em_Desenvolvimento-yellow)



## Regras do aplicativo

Criação de um aplicativo (app) para "Registro e Atendimento de Chamados". O aplicativo deverá ter:

* Tela inicial (sem login);
* Tela para cadastro da demanda (título do problema, data do cadastro, descrição, local, tipo (infraestrutura ou TI), status (pré-definido como aberto);
* Tela para listar todos os chamados;
* Tela para atendimento (campo para registrar a solução e edição do campo "status");
* Tela para listar com filtros: por data, por status (aberto, em atendimento, concluído).
